## Reporting a Vulnerability
We prioritize the security of decentralized finance infrastructure and our user community.
If you discover a security vulnerability, **please do not disclose it publicly in an issue or forum**.

Instead, please report it privately via:
- **Email:** `luca.celebrano1@gmail.com`
- **GitHub Security Advisory:** Submit a private vulnerability report directly through the GitHub Security tab on the affected repository.

### What to Include
- Detailed description of the vulnerability.
- Proof of Concept (PoC) or reproducible steps.
- Affected components or smart contract addresses.
- Potential impact assessment.

We commit to acknowledging your report within 24 hours and providing a remediation timeline.
